{ ============================================================================
  NOME DELLO STUDY:  S1144         (nome libero)

  RICOCHET - NQ LUNGO DOPO UN GIORNO IN CALO - 1144 NQ 5 minuti, "grezzo OP800"
  (paper: Hu, Jin, Wang 2025, "Autocorrelation in Daily Stock Market Returns:
  Time-variation and Asymmetry", SSRN 5314371: dopo i giorni negativi i
  rimbalzi sono piu' probabili.)

  LA REGOLA (barre da 5 minuti, ora di Chicago):
  1. Segnale: la seduta REGOLARE di ieri (apertura = chiusura della barra
     delle 08:30; chiusura = chiusura della barra delle 15:00, o delle 12:00
     nelle mezze giornate) ha chiuso SOTTO l'apertura (soglia 0 %). "Ieri" e'
     l'ultima seduta regolare valida: le feste della lista si saltano.
  2. Entrata: LUNGO alla CHIUSURA della barra delle 17:05 (la prima della
     seduta CME), se la seduta che comincia non e' una festa della lista.
  3. Stop 50 punti (1.000 $ sul mini) e target 100 punti (2.000 $), per
     contratto, con SetStopLoss e SetProfitTarget; se la barra apre gia'
     oltre un livello, si esce all'apertura.
  4. Rientri (al massimo 4 operazioni per seduta): dopo un'uscita allo stop
     o al target, passata 1 barra dalla barra d'uscita, si rientra LUNGO alla
     chiusura della prima barra, prima dell'uscita a orario, in cui:
       - il minimo tocca il pivot S1 di ieri piu' un margine di 0,15 ATR 14
         giornaliero di ieri: Low <= S1 + Margine;
       - la chiusura e' sopra S1: Close > S1.
     S1 = 2 x P - massimo di ieri, P = (massimo + minimo + chiusura) / 3 della
     seduta regolare di ieri (barre 08:35-15:00). Stesso stop, stesso target.
  5. Uscita a orario: alla chiusura della prima barra che chiude alle 15:00 o
     dopo. Da li' niente piu' rientri nella seduta.
  ATR 14 giornaliero: sedute regolari 08:35-15:00 (massimo, minimo; chiusura
  delle 15:00, o delle 12:00 nelle mezze giornate), non festive, sempre di
  IERI, alla Wilder come pandas (finche' non ci sono 14 sedute regolari il
  margine e' 0).

  ATTENZIONE - NON ANCORA VERIFICATO: scritto il 04/11/2026 sulla struttura di
  S1000 (verificato 2021/2021 con l'emulatore), ma questo codice NON e' ancora
  stato confrontato operazione per operazione con le 2.238 operazioni di
  riferimento, ne' compilato in MultiCharts. Prima di usarlo: emulatore e
  confronto, come per S1000. Limite noto: nelle mezze giornate (chiusura CME
  alle 12:15) non c'e' una barra alle 15:00; la posizione resta aperta e la
  chiude la sicurezza alla prima barra della seduta dopo (in Valeris esce
  sull'ultima barra della seduta).

  IMPOSTAZIONI DEL GRAFICO
  Data1 = @NQ (o @MNQ), 5 MINUTI. Time zone = Exchange (ora di Chicago).
  Sessione COMPLETA CME Globex 17:00-16:00, barre marcate alla chiusura.
  Continuo NON aggiustato. Storia: almeno 30 sedute prima del primo giorno
  che interessa (ATR di Wilder). Maximum number of bars study will reference
  = 5. Intrabar Order Generation = NO. Bar Magnifier spento.
  Nomi d'ordine: 1144 L (base), 1144 RL (rientro), 1144 fine LX (uscita a
  orario), 1144 sic LX (sicurezza), piu' Stop Loss e Profit Target.
  Feste (sedute senza seduta regolare valida, le stesse di Valeris) fino al

  L'esecuzione automatica resta SPENTA finche' non la accendi tu.

{ ==========================================================================
  1. SEDUTA: una barra dopo le 16:30 appartiene alla seduta del giorno dopo.
  All'inizio di ogni seduta la seduta regolare appena finita (con la barra
  delle 08:30 e quella delle 12:00 o delle 15:00, non festiva) diventa "ieri":
  apertura, massimo, minimo, chiusura (pivot e segnale) e ATR 14.
  ========================================================================== }
if Time > 1630 then
    NuovaSeduta = CurrentBar > 1 and ( Time[1] <= 1630 or Date[1] <> Date )
else
    NuovaSeduta = CurrentBar > 1 and Time[1] <= 1630 and Date[1] <> Date;

if NuovaSeduta then begin
    if Ha830 and ( Ha1200 or Ha1500 ) and Festa = false and PrimaReg = false then begin
        if Ha1500 then ChiOggi = Chi1500 else ChiOggi = Chi1200;
        NReg = NReg + 1;
        RangeOggi = MaxReg - MinReg;
        if NReg = 1 then TrG = RangeOggi
        else TrG = MaxList( RangeOggi, AbsValue( MaxReg - ChiIeri ), AbsValue( MinReg - ChiIeri ) );
        if NReg = 1 then WAtr = TrG
        else if WAtr <> TrG then WAtr = ( FG * WAtr + AG * TrG ) / ( FG + AG );
        AtrOk = NReg >= AtrGiorni;
        AtrIeri = WAtr;
        ChiIeri = ChiOggi;
        ApIeri = Ap830;
        MaxIeri = MaxReg;
        MinIeri = MinReg;
        IeriOk = true;
    end;
    if MarketPosition > 0 then Sell ( "1144 sic LX" ) this bar on close;
    if MarketPosition <> 0 then Print( "S1144 AVVISO ", Date, " ", Time, " posizione aperta a inizio seduta: chiusa" );
end;

if NuovaSeduta or CurrentBar = 1 then begin
    if Time > 1630 then SessData = JulianToDate( DateToJulian( Date ) + 1 ) else SessData = Date;
    Festa = false;
    for jj = 0 to NFeste - 1 begin
        if Feste[jj] = SessData then Festa = true;
    end;
    Esclusa = false;
    if SaltaSenza830 = 1 then begin
        for jj = 0 to NSenza - 1 begin
            if Senza830[jj] = SessData then Esclusa = true;
        end;
    end;
    Ha830 = false;
    Ha1200 = false;
    Ha1500 = false;
    PrimaReg = true;
    HaFi = false;
    Fase = 0;
    NTrade = 0;
    InPos = false;
    BarIn = -1;
    UscitaBar = -1;
    if AtrOk then Marg = MargAtr * AtrIeri else Marg = 0;
    { il segnale e il pivot S1 di ieri }

    if IeriOk and ApIeri > 0 then
        Rossa = ChiIeri < ApIeri and ( ApIeri - ChiIeri ) / ApIeri * 100 >= SogliaPct;

end;

            Fase = 4;
            InPos = true;
            BarIn = CurrentBar;
            NTrade = NTrade + 1;
        end;
    end;

{ --- STOP and TARGET as explicit orders (Claude 2026-11-09): replaces SetStopLoss / SetProfitTarget, which did not fire in our
  MultiCharts install (Dual Thrust notes). An entry 'this bar on close' fills at this bar's Close, so on the entry bar the brackets are
  referenced to Close; from the next bar on, to EntryPrice. Run with Bar Magnifier on at 1 minute (the Python port walks 1-minute bars). --- }

    if StopPunti > 0 then Sell ( "1144 SL0" ) next bar at Close - StopPunti stop;
    if TargetPunti > 0 then Sell ( "1144 TP0" ) next bar at Close + TargetPunti limit;
end
else if MarketPosition > 0 then begin
    if StopPunti > 0 then Sell ( "1144 SL" ) next bar at EntryPrice - StopPunti stop;
    if TargetPunti > 0 then Sell ( "1144 TP" ) next bar at EntryPrice + TargetPunti limit;
end;
