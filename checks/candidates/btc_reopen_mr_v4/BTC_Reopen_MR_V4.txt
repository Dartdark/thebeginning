{=============================================================================
 BTC REOPEN MR V4 (H1B_z_lb60_abs1.5) - MultiCharts PowerLanguage port (2026-10-24)
 Port of the NinjaTrader 8 strategy BTCFuturesReopenResidualFairValueV4 (@ElementOfFear; concept from
 Matteo's BTC reopen video). Source: checks/candidates/btc_reopen_mr_v4/NinjaTrader/. Logic kept as coded;
 differences are listed under PORT NOTES.

 WHAT IT DOES
   CME BTC futures close 16:00-17:00 CT (Mon-Thu) and Fri 16:00 -> Sun 17:00 CT; spot BTCUSD keeps trading.
   At the FIRST futures bar after a scheduled 17:00 CT reopen:
     residual (bps) = 10000 x [ (futures reopen close / futures last pre-close close - 1)
                              - (spot now / spot at the futures pre-close bar - 1) ]
   Z = (residual - mean) / sd of the previous 60 eligible residuals (sample sd).
   |Z| >= 1.5 -> FADE it: Z > 0 short, Z < 0 long, market order next bar. Exit 60 clock minutes after
   the entry fill (market order next bar). No stop, no target. One position.

 CHART (both series must be in CENTRAL time)
   Data1: CME BTC futures 1-minute (continuous, NOT back-adjusted), Exchange time (CT), CME session with the
          16:00-17:00 CT break. 1-minute only (the reopen detector needs gaps >= 30 min).
   Data2: spot BTCUSD 1-minute (Coinbase), 24/7 session, time zone set to the SAME Central time as Data1
          (Format Instrument > Settings > Time Zone). Spot older than 5 minutes = no signal.
   IOG off. Costs are not in the code: set commission / slippage in the strategy properties.

 EVENT GATE (as the source): a scheduled reopen R (Mon-Thu 17:00 CT after a 16:00 close; Sun 17:00 CT after
   Fri 16:00) between the previous and the current futures bar; once per R; not a special-session date
   (weekend: Sunday or Friday date); futures gap >= 30 min; current bar <= R + 15 min; previous bar <=
   close + 15 min; not in the post-roll warm-up (60 bars with spot after each roll date).

 PORT NOTES
   - Special-session dates: the author's list 2018-07-04 .. 2024-07-04 exactly, then CME holidays / early
     closes 2024-09 .. 2027 added here (extend each year, like the other strategies' 2027 lists).
   - Roll dates: the author's NinjaTrader ledger 2018-06-28 .. 2024-08-23 exactly, then "Thursday before the
     last Friday of the month" (the ledger's usual rule) to 2030. Your MultiCharts continuous series may roll
     on other days: a roll that falls on a reopen makes a fake residual. Check QuoteManager's roll dates.
   - StartDateEL / EndDateEL = the author's research window (2018-06-11 .. 2024-09-01) when set; defaults
     0 = no limit. A position open past EndDateEL is closed (as the source's terminal exit).
   - Sizing: NumContracts on Data1's contract (BTC = 5 coins; MBT = 0.1 coin). The author reports the
     micro (MBT) version failed after spread and commission, and realistic bid/ask fills cut the native
     result by ~64% (PF 2.0 -> 1.27). Untested here (no spot BTCUSD data in the repo).
   - Trades run ~17:01 -> 18:02 CT: inside Apex's hours (flat by 15:59 does not apply to them).
=============================================================================}

CurDT = ELDateToDateTime(Date) + ELTimeToDateTime(Time);

If CurDT > LastDoneDT then begin              // once per Data1 bar (guards calculations on Data2 bars)
    LastDoneDT = CurDT;

    // ---- spot at or before this futures bar, fresh within MaximumSpotAgeMinutes ----
    SpotNow = Close of data2;
    SpotDT = ELDateToDateTime(Date of data2) + ELTimeToDateTime(Time of data2);
    SpotAge = (CurDT - SpotDT) * 1440;
    HasSpot = SpotNow > 0 and SpotAge >= -0.001 and SpotAge <= MaximumSpotAgeMinutes + 0.001;

    // ---- position bookkeeping ----
    If MarketPosition = 0 then begin
        HasFill = false;
        ForcedPending = false;
    end
    else if HasFill = false then begin
        FillDT = CurDT;                         // the entry filled at this bar (next-bar market order)
        HasFill = true;
    end;

    // ---- roll dates: arm the post-roll warm-up, force an exit if a position is open ----
    If UseRollGuard and RollIdx < NRo and Date >= RoD[RollIdx] then begin
        While RollIdx < NRo and Date >= RoD[RollIdx] begin
            RollIdx = RollIdx + 1;
        end;
        WarmupActive = true;
        PostRollSamples = 0;
        If MarketPosition <> 0 and ForcedPending = false then ForcedPending = true;
        If PrintDiag then Print("BTCMR ROLLOVER ", ELDateToString(Date), " ", Time:0:0);
    end;
    If EndDateEL > 0 and Date > EndDateEL and MarketPosition <> 0 then ForcedPending = true;

    // ---- exits: forced (roll / window end) or 60 clock minutes from the fill ----
    If MarketPosition <> 0 and (ForcedPending
       or (HasFill and CurDT >= FillDT + ExecutableExitHoldMinutes / 1440 - 0.0000001)) then begin
        If MarketPosition > 0 then Sell ("ExitL") next bar at market
        else BuyToCover ("ExitS") next bar at market;
    end;

    // ---- reopen event gate ----
    If HasPrev and MarketPosition = 0 then begin
        GapMin = (CurDT - PrevDT) * 1440;
        Eligible = (StartDateEL = 0 or Date >= StartDateEL) and (EndDateEL = 0 or Date <= EndDateEL);
        RBest = 0;
        If Eligible then begin
            For kk = 0 to 1 begin                // candidate reopens on the previous and the current date
                If kk = 0 then DCand = Date[1] else DCand = Date;
                If kk = 0 or Date <> Date[1] then begin
                    Dow = DayOfWeek(DCand);
                    If Dow >= 0 and Dow <= 4 then begin
                        RCand = ELDateToDateTime(DCand) + 17 / 24;
                        If RCand > PrevDT + 0.0000001 and RCand <= CurDT + 0.0000001
                           and (RBest = 0 or RCand < RBest) then begin
                            RBest = RCand;
                            RBestEL = DCand;
                            WkBest = (Dow = 0);
                            If WkBest then begin
                                CloseBest = ELDateToDateTime(DCand) - 2 + 16 / 24;
                                FriEL = JulianToDate(DateToJulian(DCand) - 2);
                            end
                            else CloseBest = ELDateToDateTime(DCand) + 16 / 24;
                        end;
                    end;
                end;
            end;
            Eligible = RBest > 0 and AbsValue(RBest - LastR) > 0.0000001;
        end;
        If Eligible then begin
            LastR = RBest;                       // processed once, whatever the later checks say
            Excl = false;
            For kk = 0 to NEx - 1 begin
                If ExD[kk] = RBestEL or (WkBest and ExD[kk] = FriEL) then Excl = true;
            end;
            LagMin = (CurDT - RBest) * 1440;
            AfterClose = (PrevDT - CloseBest) * 1440;
            Eligible = (Excl = false) and GapMin >= MinimumFuturesClosedMinutes
                       and LagMin >= -0.001 and LagMin <= 15.001 and AfterClose <= 15.001;
            If Eligible and WarmupActive then begin
                If PostRollSamples >= ResidualLookbackEvents then WarmupActive = false
                else Eligible = false;
            end;
        end;

        // ---- residual, Z, entry ----
        If Eligible and HasSpotPrev and HasSpot and SpotPrev > 0 and SpotNow > 0 and FutPrev > 0 and Close > 0 then begin
            SpotGap = SpotNow / SpotPrev - 1;
            FutRet = Close / FutPrev - 1;
            ResidBps = 10000 * (FutRet - SpotGap);
            ReadyZ = NRes >= ResidualLookbackEvents;
            Zv = 0;
            If ReadyZ then begin
                RMean = 0;
                For kk = 0 to ResidualLookbackEvents - 1 begin RMean = RMean + Res[kk]; end;
                RMean = RMean / ResidualLookbackEvents;
                Sse = 0;
                For kk = 0 to ResidualLookbackEvents - 1 begin Sse = Sse + Square(Res[kk] - RMean); end;
                RStd = SquareRoot(Sse / (ResidualLookbackEvents - 1));
                If RStd > 0.000000000001 then Zv = (ResidBps - RMean) / RStd else ReadyZ = false;
            end;
            Res[ResHead] = ResidBps;                    // add AFTER the baseline read (current excluded)
            ResHead = Mod(ResHead + 1, ResidualLookbackEvents);
            If NRes < ResidualLookbackEvents then NRes = NRes + 1;
            If PrintDiag then
                Print("BTCMR ", ELDateToString(Date), " ", Time:0:0, " resid ", ResidBps:0:2, " z ", Zv:0:3, " ready ", IFF(ReadyZ, 1, 0):0:0);
            If ReadyZ and AbsValue(Zv) >= AbsResidualZThreshold then begin
                If Zv > 0 then SellShort ("H1_S") NumContracts contracts next bar at market
                else Buy ("H1_L") NumContracts contracts next bar at market;
            end;
        end;
    end;

    // ---- post-roll warm-up samples; anchors for the next bar ----
    If HasSpot and SpotNow > 0 and Close > 0 and WarmupActive then PostRollSamples = PostRollSamples + 1;
    FutPrev = Close;
    SpotPrev = SpotNow;
    HasSpotPrev = HasSpot;
    PrevDT = CurDT;
    HasPrev = true;
end;
