{ Apex_Account_Check - INDICATOR (no orders). Step 1 of automatic cushion sizing (Claude, 2026-10-23).
  Prints what MultiCharts receives from Rithmic for this chart's account, so we know whether a strategy can read the
  account balance by itself. Put it on any live chart (e.g. the VB chart) during the session, with auto-trading on, and
  read the Output window (View > Output / PowerLanguage Editor Output). It prints once a minute.
  AccountName: REQUIRED, type the account exactly (e.g. APEX-681524-01). If blank it does nothing and prints a warning:
  GetAccount(1) would return the first account in the broker list, not this chart's (Codex, cross-review 2026-10-23).
  Test it on TWO charts with the two accounts (-01 and -02): each line must show its own account and its own balance.
  Send Claude a screenshot of the lines and the Apex dashboard balances at the same time. }

Inputs: AccountName("");
Vars: Acct(""), NW(0), EQ(0), LastMin(-1);

If GetAppInfo(aiRealTimeCalc) = 1 and LastBarOnChart then begin
	Acct = AccountName;
	If Acct = "" then begin
		If LastMin < 0 then Print("Apex_Account_Check: set the AccountName input (e.g. APEX-681524-01); nothing checked.");
		LastMin = 0;
	end
	else if Mod(Time, 100) <> LastMin then begin
		LastMin = Mod(Time, 100);
		NW = GetRTAccountNetWorth(Acct);
		EQ = GetRTAccountEquity(Acct);
		Print("Apex_Account_Check ", NumToStr(Date, 0), " ", NumToStr(Time, 0), " account=[", Acct, "] NetWorth=",
			NumToStr(NW, 2), " Equity=", NumToStr(EQ, 2));
	end;
end;
Plot1(0, "Check");
