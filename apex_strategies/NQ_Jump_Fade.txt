{ NQ JUMP FADE v2 (morning 5-minute jump fade)  -  2026-11-12 (v2: stop and target re-sent every bar), WATCHLIST #40, POST-HOC LEAD: FORWARD LOG / SIM ONLY
  =====================================================================================================================
  Research: analysis/jump_morning_fade.py (2018-2026: 694 trades, 77.5% wins, $117 per NQ after costs, PF 1.35, t 2.7 vs the
  multiple-testing bar 3.70; found after 4,368 versions, so NOT proven). Books: analysis/jump_morning_fade_bench.py.
  Python port of THIS code (check before trusting a report): analysis/jump_fade_pl_port.py.

  IDEA   A 5-minute bar whose move is far above normal for its time of day ("jump score" |J| > 3, Marcaccioli, Bouchaud &
         Benzaquen 2021) closing between 07:00 and 09:59 CT is faded: enter AGAINST it at the next minute's open.
  EXITS  stop 1.5 x the jump bar's high-low range; target 0.3 x the stop (0.45 x range); out after 240 one-minute bars;
         flat at 15:55 CT (11:30 CT on CME early-close days). One position at a time.
  SCORE  r = 5-min close - previous 5-min close (none after a gap > 10 min)
         sig = sqrt( pi/2 x mean( |r_i| x |r_i-1| ) ) over the previous 276 5-min bars (needs 138 valid), this bar excluded
         x = |r| / sig;  fraw = mean x of the same 5-min time slot over its previous 60 sessions (needs 20)
         f = fraw / mean fraw of the last 5,520 5-min bars incl. this one (needs 1,380);  J = r / (sig x f)

  CHART  @NQ or @MNQ, 1-MINUTE bars, 24h CME Globex session (17:00-16:00 CT), Exchange time (Central), bars stamped at
         their CLOSE (MultiCharts default). Data1 only. Load at least 4 MONTHS of history (the score needs ~20 sessions per
         slot plus 20 days of normaliser before the first trade). Max bars back: 5 (manual).
  PROPS  Intrabar order generation OFF, no multiple entries, Bar Magnifier not needed (1-min chart), commission / slippage 0
         in the report (costs are added in Python), fill limit price exceeded by 1 tick.
  SIZE   Qty contracts (MNQ: the stop averages ~$200 per MNQ, worst research loss ~$730 per MNQ). Personal book bench: 1-2 MNQ.
  NOT INCLUDED (forward log first): kill switch, heartbeat, cushion guard, finish mode. Add the live blocks
         (apex_strategies/Strategy_Heartbeat_Snippet.txt, Twin_Continuation_150K.txt) before it trades a real account.
  DIFFERENCES vs the Python research: entries are not skipped across a data gap; when a 5-min bucket has no bar at its
         :x0 / :x5 minute, the bar is closed one minute late (next bucket's first bar) and the entry is one minute later.
  ===================================================================================================================== }

Inputs:
    Qty( 1 ),
    JThr( 3 ),            { |J| above this = a jump }
    WinStart( 700 ),      { CT, close time of the first 5-min bar that can signal (07:00 = the 06:56-07:00 bar) }
    WinEnd( 955 ),        { CT, close time of the last one (09:55 = the 09:51-09:55 bar) }
    StopMult( 1.5 ),      { stop = StopMult x jump-bar range }
    TgtFrac( 0.3 ),       { target = TgtFrac x stop }
    MinRPts( 2 ),         { skip when the stop would be under this many points }
    MaxBars( 240 ),       { 1-min bars in the trade, then out at market }
    FlatTime( 1555 ),     { CT: out at the next bar's open from this bar's close on }
    UseHolidayTimes( true ),
    EarlyFlatten( 1130 ), { CT: flat from this bar on CME early-close days }
    KLen( 276 ), KMin( 138 ), SlotLen( 60 ), SlotMin( 20 ), NormLen( 5520 ), NormMin( 1380 ),
    DebugLog( false );    { true: print every finished 5-min bar inside the window (date, time, r, sig, f, J) to the Output }

Arrays:
    Prod[276]( 0 ), ProdOk[276]( 0 ),
    SlotX[288, 60]( 0 ), SlotOk[288, 60]( 0 ), SlotPos[288]( 0 ), SlotSum[288]( 0 ), SlotCnt[288]( 0 ),
    NormV[5520]( 0 ), NormOk[5520]( 0 );

Vars:
    Mins( 0 ), EndM( 0 ), BKey( 0 ), CurKey( -1 ), PrevBarKey( -1 ), Pending( false ),
    BH( 0 ), BL( 0 ), BC( 0 ), BN( 0 ), BEnd( 0 ), DoFin( false ), FinKey( 0 ), FinEnd( 0 ), FinH( 0 ), FinL( 0 ), FinC( 0 ), FinN( 0 ),
    PrevC( 0 ), HavePrev( false ), R5( 0 ), ROk( false ), A5( 0 ), APrev( 0 ), APrevOk( false ),
    PSum( 0 ), PCnt( 0 ), PPos( 0 ), Sig( 0 ), SigOk( false ), Xv( 0 ), XOk( false ),
    Sl( 0 ), SP( 0 ), FRaw( 0 ), FRawOk( false ), NSum( 0 ), NCnt( 0 ), NPos( 0 ), FNorm( 0 ), Fv( 0 ), JOk( false ), Jv( 0 ),
    EndHHMM( 0 ), RPts( 0 ), TgtPts( 0 ), EntR( 0 ),
    CalMonth( 0 ), CalDay( 0 ), CalDow( 0 ), CalYear( 0 ), IsWeekday( false ), IsEarlyClose( false ), HolFlat( false );

Once Begin
    If BarInterval <> 1 or BarType <> 1 Then RaiseRunTimeError( "NQ Jump Fade must run on a 1-minute chart." );
    If KLen > 276 or SlotLen > 60 or NormLen > 5520 Then RaiseRunTimeError( "KLen / SlotLen / NormLen above the array sizes." );
End;

{ ===== CME early-close days (12:00 CT halt), same list as Twin_Continuation_150K.txt ===== }
CalMonth = Month( Date ); CalDay = DayOfMonth( Date ); CalDow = DayOfWeek( Date ); CalYear = Year( Date ) + 1900;
IsWeekday = CalDow >= 1 and CalDow <= 5;
IsEarlyClose = UseHolidayTimes and (
    ( CalMonth = 1 and ( ( CalDay = 1 and IsWeekday ) or ( CalDay = 2 and CalDow = 1 ) ) )
    or ( CalMonth = 1 and CalDow = 1 and CalDay >= 15 and CalDay <= 21 )
    or ( CalMonth = 2 and CalDow = 1 and CalDay >= 15 and CalDay <= 21 )
    or ( CalMonth = 5 and CalDow = 1 and CalDay >= 25 )
    or ( CalMonth = 6 and CalYear >= 2022 and ( ( CalDay = 19 and IsWeekday )
        or ( CalDay = 18 and CalDow = 5 ) or ( CalDay = 20 and CalDow = 1 ) ) )
    or ( CalMonth = 7 and ( ( ( CalDay = 3 or CalDay = 4 ) and IsWeekday ) or ( CalDay = 5 and CalDow = 1 ) ) )
    or ( CalMonth = 9 and CalDow = 1 and CalDay <= 7 )
    or ( CalMonth = 11 and CalDow = 4 and CalDay >= 22 and CalDay <= 28 )
    or ( CalMonth = 11 and CalDow = 5 and CalDay >= 23 and CalDay <= 29 )
    or ( CalMonth = 12 and ( ( ( CalDay = 24 or CalDay = 25 ) and IsWeekday ) or ( CalDay = 26 and CalDow = 1 ) ) ) );
HolFlat = IsEarlyClose and Time >= EarlyFlatten and Time < 1700;

{ ===== 5-minute buckets (t-5, t], keyed by date: a bar closing 23:56-00:00 belongs to the 00:00 bucket of the next date ===== }
Mins = TimeToMinutes( Time );
If Mod( Mins, 5 ) = 0 Then EndM = Mins Else EndM = Mins - Mod( Mins, 5 ) + 5;
BKey = DateToJulian( Date ) * 1440 + EndM;
DoFin = false;

If BKey <> CurKey Then Begin
    If Pending Then Begin                      { the previous bucket never got its :x0 / :x5 bar: close it now (late) }
        DoFin = true; FinKey = CurKey; FinEnd = BEnd; FinH = BH; FinL = BL; FinC = BC; FinN = BN;
    End;
    CurKey = BKey; BEnd = Mod( EndM, 1440 ); BH = High; BL = Low; BC = Close; BN = 1; Pending = true;
End Else Begin
    If High > BH Then BH = High;
    If Low < BL Then BL = Low;
    BC = Close; BN = BN + 1;
End;

{ two finishes can't happen on one bar: a late finish happens on a bucket's FIRST bar, which is never its :x0 / :x5 bar
  unless the bucket has one bar only; then that one-bar bucket is too thin (BN < 3) and is dropped below anyway }
If Mod( Mins, 5 ) = 0 and DoFin = false Then Begin
    DoFin = true; FinKey = CurKey; FinEnd = BEnd; FinH = BH; FinL = BL; FinC = BC; FinN = BN; Pending = false;
End;

JOk = false;
If DoFin and FinN >= 3 Then Begin
    { --- return and its validity (gap > 10 minutes since the previous kept 5-min bar = no return) --- }
    ROk = HavePrev and FinKey - PrevBarKey <= 10;
    If ROk Then R5 = FinC - PrevC Else R5 = 0;
    A5 = AbsValue( R5 );

    { --- local volatility from the PREVIOUS KLen products (this bar excluded) --- }
    SigOk = PCnt >= KMin and PSum > 0;
    If SigOk Then Sig = SquareRoot( 3.14159265358979 / 2 * PSum / PCnt ) Else Sig = 0;

    { --- push this bar's product |r_t| x |r_t-1| (valid only when both returns are) --- }
    PPos = Mod( PPos + 1, KLen );
    If ProdOk[PPos] = 1 Then Begin PSum = PSum - Prod[PPos]; PCnt = PCnt - 1; End;
    If ROk and APrevOk Then Begin Prod[PPos] = A5 * APrev; ProdOk[PPos] = 1; PSum = PSum + Prod[PPos]; PCnt = PCnt + 1; End
    Else Begin Prod[PPos] = 0; ProdOk[PPos] = 0; End;
    APrev = A5; APrevOk = ROk;

    { --- time-of-day factor: mean x of this slot's previous SlotLen sessions, then push this bar's x --- }
    XOk = ROk and SigOk;
    If XOk Then Xv = A5 / Sig Else Xv = 0;
    Sl = IntPortion( FinEnd / 5 );            { 0 .. 287 }
    FRawOk = SlotCnt[Sl] >= SlotMin;
    If FRawOk Then FRaw = SlotSum[Sl] / SlotCnt[Sl] Else FRaw = 0;
    SP = Mod( SlotPos[Sl] + 1, SlotLen ); SlotPos[Sl] = SP;
    If SlotOk[Sl, SP] = 1 Then Begin SlotSum[Sl] = SlotSum[Sl] - SlotX[Sl, SP]; SlotCnt[Sl] = SlotCnt[Sl] - 1; End;
    If XOk Then Begin SlotX[Sl, SP] = Xv; SlotOk[Sl, SP] = 1; SlotSum[Sl] = SlotSum[Sl] + Xv; SlotCnt[Sl] = SlotCnt[Sl] + 1; End
    Else Begin SlotX[Sl, SP] = 0; SlotOk[Sl, SP] = 0; End;

    { --- normaliser: mean fraw over the last NormLen 5-min bars INCLUDING this one --- }
    NPos = Mod( NPos + 1, NormLen );
    If NormOk[NPos] = 1 Then Begin NSum = NSum - NormV[NPos]; NCnt = NCnt - 1; End;
    If FRawOk Then Begin NormV[NPos] = FRaw; NormOk[NPos] = 1; NSum = NSum + FRaw; NCnt = NCnt + 1; End
    Else Begin NormV[NPos] = 0; NormOk[NPos] = 0; End;

    If FRawOk and NCnt >= NormMin and NSum > 0 and SigOk and ROk Then Begin
        FNorm = NSum / NCnt; Fv = FRaw / FNorm;
        If Fv > 0 Then Begin Jv = R5 / ( Sig * Fv ); JOk = true; End;
    End;

    PrevC = FinC; HavePrev = true; PrevBarKey = FinKey;

    EndHHMM = IntPortion( FinEnd / 60 ) * 100 + Mod( FinEnd, 60 );
    If DebugLog and EndHHMM >= WinStart and EndHHMM <= WinEnd Then
        Print( "JF,", ELDateToString( Date ), ",", EndHHMM:0:0, ",", R5:0:2, ",", Sig:0:4, ",", Fv:0:4, ",", Jv:0:3 );

    { --- entry: fade the jump, flat only --- }
    If JOk and MarketPosition = 0 and AbsValue( Jv ) > JThr and EndHHMM >= WinStart and EndHHMM <= WinEnd
       and HolFlat = false and Time < FlatTime Then Begin
        EntR = StopMult * ( FinH - FinL );
        If EntR >= MinRPts and R5 <> 0 Then Begin
            RPts = Round( EntR * 4, 0 ) / 4;
            TgtPts = Round( TgtFrac * RPts * 4, 0 ) / 4;
            If R5 > 0 Then SellShort ( "JF SE" ) Qty contracts next bar at market
            Else Buy ( "JF LE" ) Qty contracts next bar at market;
        End;
    End;
End;

{ ===== stop and target: re-sent on EVERY bar (v2 fix, 2026-11-12). Set* exits only exist on bars where the statement runs: v1 set them
  on the signal bar only, so the target lived for the entry minute alone (user's report: 26 target exits vs ~535 in Python). They act
  only while a position is open; RPts / TgtPts keep the last entry's values. ===== }
If RPts > 0 Then Begin
    SetStopShare;
    SetStopLoss( RPts * BigPointValue );
    SetProfitTarget( TgtPts * BigPointValue );
End;

{ ===== exits: time, flat time, early close, and the bar-close stop guard (MULTICHARTS_PITFALLS 'Live order rejections') ===== }
If MarketPosition <> 0 Then Begin
    If BarsSinceEntry >= MaxBars or ( Time >= FlatTime and Time < 1700 ) or HolFlat Then Begin
        If MarketPosition = 1 Then Sell ( "JF LX time" ) all contracts next bar at market
        Else BuyToCover ( "JF SX time" ) all contracts next bar at market;
    End
    Else If MarketPosition = 1 and Low <= EntryPrice - RPts Then Sell ( "JF LSG" ) all contracts next bar at market
    Else If MarketPosition = -1 and High >= EntryPrice + RPts Then BuyToCover ( "JF SSG" ) all contracts next bar at market;
End;
