{ NQ Late-Day Flow - MultiCharts PowerLanguage signal (funded plan since 2026-10-12)

  At 14:00 CT, if NQ has moved at least MinMoveAtr x the 15-day ATR from the
  8:30 open, enter in the direction of that move at the next bar's open, stop
  StopAtrPct x ATR, and exit at the close of the 14:30 bar. One trade a day.
  Skipped on CME early-close days.

  Why (forced flow): daily-reset leveraged and inverse ETFs (TQQQ, SQQQ, QLD,
  SSO, UPRO, SPXU...) must rebalance by L(L-1) x assets x the day's return
  before the cash close, always in the direction of the day's move, and other
  late-day flows (market-on-close orders, end-of-day hedging) start around the
  last hour (Cheng & Madhavan 2009; Shum et al. 2016). On big-move days that is
  one-way flow regardless of price. The effect is concentrated right after
  14:00 CT; a 14:10 start is much weaker, so keep the timing.

  Python test (analysis/letf_rebalance_test.py, 1-minute NQ, 2018-2026, per NQ
  after $7.25 and 1 tick per fill, move >= 0.4 ATR, stop 0.25 ATR, out 14:30):
  898 trades, 55% winners, $94 average, PF 1.44, t = 3.5, 7 of 9 years
  positive; 2018-22 $76, 2023-26 $116. Longs $73, shorts $119 (both work).
  Every threshold 0.3-0.5 ATR x stop 0.1-0.25 ATR is positive (t 2.9-3.9);
  windows 14:00-14:20 / 14:00-14:40 too. Placebo: the same days with a random
  side average -$13 (best of 20 runs $52). ES shows the same sign but weaker
  (t 1.2). Correlation about 0 with ONB ML, Monday Long and EOS, 0.14 with VB.
  Found in a round of about 70 comparisons (analysis/forced_flows3_test.py),
  so treat it as B-grade until MultiCharts confirms it.
  Funded bench with cushion sizing, added to the current plan at 2 MNQ:
  1-year $7,648 vs $7,153, 2-year $12,019 vs $11,612, blown 4-6% vs 9-10%.

  Apply to a 5-minute NQ / MNQ chart, Exchange time zone (Central), CME
  24-hour session (for the ATR), Bar Magnifier on at 1 minute. Load at least
  25 trading days before the backtest start.

  MULTICHARTS CONFIRMED (2026-10-12, analysis/late_day_flow_confirm.py): 895
  trades, 55% winners, $95 average, PF 1.44, t = 3.5; all 895 match the Python
  test (same side and entry, P&L correlation 1.00). Longs PF 1.39 (weaker since
  2023), shorts PF 1.48. Funded bench at 2 MNQ: 1-year $7,676 vs $7,153, 2-year
  $12,012 vs $11,612, blown 4-6% vs 9-10%.

  SIZE: funded plan NumContracts 2 on MNQ with RiskPerTrade 0 (at October
  2026 prices the 0.25 ATR stop is about $235 per MNQ, so a small RiskPerTrade
  would skip most trades). Backtest on NQ: RiskPerTrade 0, NumContracts 1. }

Inputs:
	OpenBarTime(835),       { first 5-minute bar of the session: its open is the 8:30 open }
	SignalTime(1400),       { bar closing at 14:00 -> enter at the next bar's open }
	ExitTime(1430),
	MinMoveAtr(0.40),
	StopAtrPct(0.25),
	AtrDays(15),
	RiskPerTrade(0),        { $ lost at the stop; 0 = trade NumContracts }
	NumContracts(1),
	UseHolidayTimes(true);

Variables:
	DayHi(0), DayLo(0), DayClose(0), PrevDayClose(0),
	TR(0), TrCount(0), TrIdx(0), TrSum(0), Ti(0), ATRv(0),
	OpenPx(0), MovePts(0), StopPts(0), Qty(0), TradedToday(false), DayStartTrades(0),
	CalMonth(0), CalDay(0), CalDow(0), CalYear(0), IsWeekday(false), IsEarlyClose(false);

Arrays:
	TrHist[100](0);

{ ---------- Daily ATR (weekdays, calendar dates), as in Overnight Bias ---------- }
if Date <> Date[1] then begin
	if DayClose > 0 then begin
		if DayOfWeek(Date[1]) >= 1 and DayOfWeek(Date[1]) <= 5 then begin
			if PrevDayClose > 0 then
				TR = MaxList(DayHi, PrevDayClose) - MinList(DayLo, PrevDayClose)
			else
				TR = DayHi - DayLo;
			TrHist[TrIdx] = TR;
			TrIdx = Mod(TrIdx + 1, AtrDays);
			if TrCount < AtrDays then TrCount = TrCount + 1;
		end;
		PrevDayClose = DayClose;
	end;
	DayHi = High;
	DayLo = Low;
	OpenPx = 0;
	DayStartTrades = TotalTrades;
end
else begin
	DayHi = MaxList(DayHi, High);
	DayLo = MinList(DayLo, Low);
end;
DayClose = Close;

ATRv = 0;
if TrCount >= AtrDays then begin
	TrSum = 0;
	for Ti = 0 to AtrDays - 1 begin
		TrSum = TrSum + TrHist[Ti];
	end;
	ATRv = TrSum / AtrDays;
end;

{ ---------- 8:30 open ---------- }
if Time = OpenBarTime then OpenPx = Open;

{ ---------- CME early-close days (skipped) ---------- }
CalMonth = Month(Date);
CalDay = DayOfMonth(Date);
CalDow = DayOfWeek(Date);
CalYear = Year(Date) + 1900;
IsWeekday = CalDow >= 1 and CalDow <= 5;
IsEarlyClose = UseHolidayTimes and (
	(CalMonth = 1 and ((CalDay = 1 and IsWeekday) or (CalDay = 2 and CalDow = 1)))
	or (CalMonth = 1 and CalDow = 1 and CalDay >= 15 and CalDay <= 21)
	or (CalMonth = 2 and CalDow = 1 and CalDay >= 15 and CalDay <= 21)
	or (CalMonth = 5 and CalDow = 1 and CalDay >= 25)
	or (CalMonth = 6 and CalYear >= 2022 and ((CalDay = 19 and IsWeekday)
		or (CalDay = 18 and CalDow = 5) or (CalDay = 20 and CalDow = 1)))
	or (CalMonth = 7 and (((CalDay = 3 or CalDay = 4) and IsWeekday) or (CalDay = 5 and CalDow = 1)))
	or (CalMonth = 9 and CalDow = 1 and CalDay <= 7)
	or (CalMonth = 11 and CalDow = 4 and CalDay >= 22 and CalDay <= 28)
	or (CalMonth = 11 and CalDow = 5 and CalDay >= 23 and CalDay <= 29)
	or (CalMonth = 12 and (((CalDay = 24 or CalDay = 25) and IsWeekday) or (CalDay = 26 and CalDow = 1))));

{ ---------- Entry at 14:00 in the direction of a big move ---------- }
TradedToday = MarketPosition <> 0 or TotalTrades > DayStartTrades;
if Time = SignalTime and IsEarlyClose = false and OpenPx > 0 and ATRv > 0
	and MarketPosition = 0 and TradedToday = false then begin
	MovePts = Close - OpenPx;
	if AbsValue(MovePts) >= MinMoveAtr * ATRv then begin
		StopPts = StopAtrPct * ATRv;
		Qty = NumContracts;
		if RiskPerTrade > 0 then Qty = Floor(RiskPerTrade / (StopPts * BigPointValue));
		if Qty >= 1 then begin
			if MovePts > 0 then
				Buy ("LateFlow L") Qty contracts next bar at market
			else
				SellShort ("LateFlow S") Qty contracts next bar at market;
		end;
	end;
end;

{ ---------- Exits ---------- }
SetStopContract;
if StopPts > 0 then SetStopLoss(StopPts * BigPointValue);
{ live stop guard (2026-10-17, as EOS 2026-10-16): Rithmic rejects a protective stop that is already through the market
  ("Invalid StopMarket order parameters"), which leaves the position without its stop. If the position is still open at the
  close of a bar that traded at or through the stop level, exit at market on the next bar. In a backtest the stop has always
  filled inside that bar first, so the guard never fires there (backtests unchanged). }
if MarketPosition > 0 and StopPts > 0 and Low <= EntryPrice - StopPts then
	Sell ("LateFlow LSG") next bar at market;
if MarketPosition < 0 and StopPts > 0 and High >= EntryPrice + StopPts then
	BuyToCover ("LateFlow SSG") next bar at market;

if MarketPosition <> 0 and Time >= ExitTime then begin
	Sell ("LateFlow LX") this bar on close;
	BuyToCover ("LateFlow SX") this bar on close;
end;
