{ BTC ADX Longs - MultiCharts PowerLanguage signal (PERSONAL account; written 2026-11-14, NOT YET COMPILED OR BACKTESTED)

  The user's Jesse strategy 'BTCAdxEnsembleFree' (pasted 2026-11-13), personal plan: LONG books only, 1 MBT a book, 2 books.
  Signals come from SPOT bitcoin (Coinbase) as in the test; every long book is copied to CME Micro Bitcoin (MBT).

  SPOT RULE (paper, both sides, exactly as analysis/btc_adx_ensemble_test.py run()):
  - 1h, 4h and daily candles are built here from the spot 15-minute bars on UTC boundaries (as the exchange / Jesse do).
  - At each 1h close: side = +1 if close > EMA(200) of the completed 4h closes, else -1; no signal unless the close is on the same
    side of SuperTrend(10, 3) (1h), Bollinger(20, 2) width < 15% (1h), and the 20 / 120 daily return-vol ratio < 1.5 (daily =
    the 4h candle opening 16:00 UTC; skipped until 121 such closes exist).
  - Two books, ADX(14) > 40 and > 50. A book opens when empty, ADX above its level, and not against the other open book's side.
  - Each book on every spot 15m close, in order: guard (a stop 1% beyond the farthest open book stop: every book out, no entries
    on that candle); stop (low <= entry - 2.5 ATR); target (high >= entry + 8 ATR); half-off at 1.5 ATR (paper only); out after
    240 hours or at a 1h close on the other side of the 4h EMA.
  - Short books are kept on paper only: they occupy their book and block longs, as in the benched version.
  REAL ORDERS (as analysis/btc_adx_whole_contract_check.py version (a), 2026-11-14):
  - A paper LONG book opening -> buy BookQty MBT next bar at market (entry name 'BTC B1' = ADX 40 book, 'BTC B2' = ADX 50 book).
  - A resting sell stop at fill x (1 - R), R = 2.5 x ATR / spot entry; once stopped, that book's contract is not re-bought.
  - The paper book closing for any reason -> sell its contract next bar at market. The half-off is NOT traded (1 contract a book
    cannot be halved; ignoring it tested better: book return/DD +0.13 on 2019-26 vs the plan's half-contract version).
  - Python, version (a): about $1,518 a year per MBT pair (2 books), max DD $2,051, 2022 -$998; book return/DD 7.03 -> 7.30.

  CHART SETUP
  - Data1: @MBT, 15 minutes, Exchange time zone (Central), 24-hour session. (For a backtest before May 2021, use @BTC and
    divide the dollar results by 50.)
  - Data2: spot BTC-USD 15 minutes, SAME time zone (Central), a 24 / 7 session. For the backtest: Map ASCII our Coinbase files
    data/BTCUSD_spot_1min_*.csv (Central time, stamped at the bar CLOSE), compression 15 minutes. LIVE needs a real-time spot
    feed for data2 (Coinbase BTC-USD or another USD spot index); without one, do not run this live.
  - Format Signals > Properties: Maximum bars referenced (MaxBarsBack) 3000; Position Limits: allow up to 2 entry orders in the
    same direction 'if the order is generated by another entry order'; intra-bar order generation OFF; Bar Magnifier 1 minute.
  - Load at least 6 months of data before the backtest start: the daily vol ratio needs 121 days and EMA(200) 800 hours; no
    trade is taken before both are ready.
  - Compile the function PS_UTCOffsetCT first (personal_strategies/functions/PS_UTCOffsetCT.txt).

  ROLLS (checker 2026-11-14): backtest on a BACK-ADJUSTED continuous MBT / BTC series (unadjusted adds about +$1,010 and 4
  stops since 2019-07). Live: MBT expires the last Friday of each month and a book can be open then; there is no roll
  procedure yet. Do not go live until one is written (TODO).

  KNOWN DIFFERENCES FROM THE PYTHON TEST (check them in the MultiCharts report)
  - Entries and spot exits fill at the next MBT bar's open (Python: the signal bar's close + 1 tick).
  - On the bar an entry fills, the resting stop is not yet live: a bar-close guard exits at market next bar instead.
  - A book that closes and reopens long before the next MBT bar keeps its contract (Python: sell and buy at the same price).
  - Indicators are warmed up from the first bar the chart loads, so the first months may differ slightly from Python's. }

DefineDLLFunc: "kernel32.dll", int, "GetFileAttributesA", lpstr;
DefineDLLFunc: "kernel32.dll", int, "GetLastError";

Inputs:
	BookQty(1),            { MBT contracts per long book }
	Level1(40), Level2(50),
	StopAtr(2.5), HalfAtr(1.5), TargetAtr(8), MaxHours(240),
	BBWMax(15), VolRatioMax(1.5), GuardPct(1),
	ScanMax(2900),         { most spot bars caught up in one MBT bar (CME closures); keep below MaxBarsBack }
	HeartbeatTag("");      { live guard: the chart's logger tag; empty = no heartbeat }

Variables:
	LastKey(0), kmax(0), j(0), Found(true), ps(0), q4(0), DoFin(false), Do4(false), pdi(0), ndi(0), i0(0), b(0), dd(0), tm(0), ck(0), ok(0), oh(0), hh(0), ll(0), cc(0), he(false),
	HB(-1), HOp(0), HHi(0), HLo(0), HCl(0), HasH(false), NH(0), PrevC(0), TRv(0), UpM(0), DnM(0), PrevH(0), PrevL(0),
	A14(0), A10(0), P14(0), Q14(0), SA(0), SA10(0), SP(0), SQ(0), DXv(0), ADXv(0), SDX(0),
	UB(0), LB(0), FU(0), FL(0), STv(0), TrUp(true), STok(false), BBW(100), k(0), smb(0), sqb(0),
	C4B(-1), L4C(0), Has4(false), N4(0), EMA4(0), ND(0), VR(0), m1(0), m2(0), s1(0), s2(0), lr(0), Ready(false),
	lt(0), side(0), net(0), anyOpen(false), gs(0), g(0), gHit(false), lvl(0),
	KillOn(false), NoEntry(false), KillAttr(-1), KillErr(0), HB_Last(-1), HB_Key(0), HB_Day(""), HB_Ver("BTC_ADX_Longs 2026-11-14");
Arrays:
	BkOn[2](false), BkS[2](0), BkE[2](0), BkStop[2](0), BkPt[2](0), BkTp[2](0), BkHalf[2](false), BkT[2](0), BkR[2](0), BkId[2](0),
	RState[2](0), RealId[2](0), StopId[2](0), RR[2](0), RStop[2](0), StopLive[2](false), WantId[2](0),
	CB[20](0), DC[121](0);
Variables: NextId(0);

{ ---------- kill switch (live/vps/KILL_SWITCH.md; real time only) ---------- }
KillOn = false; KillAttr = -1; KillErr = 0;
if GetAppInfo(aiRealTimeCalc) = 1 then begin
	KillAttr = GetFileAttributesA("C:\TradingLogs\KILL");
	if KillAttr <> -1 then KillOn = true else KillErr = GetLastError;
end;
NoEntry = KillOn;
if GetAppInfo(aiRealTimeCalc) = 1 and GetFileAttributesA("C:\TradingLogs") = -1 then NoEntry = true;
if GetAppInfo(aiRealTimeCalc) = 1 and KillAttr = -1 and KillErr <> 2 and KillErr <> 3 then NoEntry = true;

{ ---------- real side, start of bar: fills of the orders sent on the previous bar ---------- }
for b = 1 to 2 begin
	if RState[b] = 2 and StopLive[b] and Low <= RStop[b] then begin RState[b] = 0; StopId[b] = RealId[b]; end;   { resting stop filled }
	if RState[b] = 1 then begin                                     { entry filled at this bar's open }
		RState[b] = 2; RStop[b] = Open * (1 - RR[b]); StopLive[b] = false;
	end;
end;

{ ---------- catch up every spot 15m bar closed since the last MBT bar, oldest first ---------- }
j = 0; Found = true;
while Found and j <= ScanMax begin
	dd = Date[j] of data2; tm = Time[j] of data2;
	ck = DateToJulian(dd) * 1440 + IntPortion(tm / 100) * 60 + Mod(tm, 100) + PS_UTCOffsetCT(dd, tm) * 60;   { UTC minutes, bar close }
	if ck > LastKey then j = j + 1 else Found = false;
end;
kmax = j - 1;

for j = kmax downto 0 begin
	dd = Date[j] of data2; tm = Time[j] of data2;
	ck = DateToJulian(dd) * 1440 + IntPortion(tm / 100) * 60 + Mod(tm, 100) + PS_UTCOffsetCT(dd, tm) * 60;
	if ck > LastKey then begin    { skip a repeated / out-of-order stamp (DST changeover; checker 2026-11-14) }
	ok = ck - 15;                                   { candle OPEN, UTC minutes }
	oh = Open[j] of data2; hh = High[j] of data2; ll = Low[j] of data2; cc = Close[j] of data2;
	he = (Mod(ok, 60) = 45);                        { the 15m candle that ends a UTC hour }

	{ ===== candles: pass 1 = finalize an unfinished earlier hour, pass 2 = add this candle, pass 3 = finalize at the hour end ===== }
	for ps = 1 to 3 begin
		DoFin = false;
		if ps = 1 then DoFin = HasH and IntPortion(ok / 60) <> HB;
		if ps = 2 then begin
			if HasH = false then begin HB = IntPortion(ok / 60); HOp = oh; HHi = hh; HLo = ll; HasH = true; end
			else begin if hh > HHi then HHi = hh; if ll < HLo then HLo = ll; end;
			HCl = cc;
		end;
		if ps = 3 then DoFin = he and HasH;
		if DoFin then begin
			{ ----- 1h indicators (TA-Lib style Wilder seeding, as analysis/btc_adx_ensemble_test.py indicators()) ----- }
			i0 = NH;                                         { 0-based index of this hour }
			NH = NH + 1;
			if i0 = 0 then begin TRv = HHi - HLo; UpM = 0; DnM = 0; end
			else begin
				TRv = MaxList(HHi - HLo, AbsValue(HHi - PrevC), AbsValue(HLo - PrevC));
				UpM = HHi - PrevH; DnM = PrevL - HLo;
				if UpM > DnM and UpM > 0 then value2 = UpM else value2 = 0;
				if DnM > UpM and DnM > 0 then value3 = DnM else value3 = 0;
				UpM = value2; DnM = value3;
			end;
			if i0 >= 1 and i0 <= 14 then begin SA = SA + TRv; SP = SP + UpM; SQ = SQ + DnM; end;
			if i0 = 14 then begin A14 = SA / 14; P14 = SP / 14; Q14 = SQ / 14; end;
			if i0 > 14 then begin A14 = A14 + (TRv - A14) / 14; P14 = P14 + (UpM - P14) / 14; Q14 = Q14 + (DnM - Q14) / 14; end;
			if i0 >= 1 and i0 <= 10 then SA10 = SA10 + TRv;
			if i0 = 10 then A10 = SA10 / 10;
			if i0 > 10 then A10 = A10 + (TRv - A10) / 10;
			if i0 >= 14 and A14 > 0 then begin
				pdi = 100 * P14 / A14; ndi = 100 * Q14 / A14;
				if pdi + ndi > 0 then DXv = 100 * AbsValue(pdi - ndi) / (pdi + ndi) else DXv = 0;
				if i0 <= 27 then SDX = SDX + DXv;
				if i0 = 27 then ADXv = SDX / 14;
				if i0 > 27 then ADXv = ADXv + (DXv - ADXv) / 14;
			end;
			{ SuperTrend(10, 3) on hl2 with ATR(10) }
			if i0 >= 10 then begin
				UB = (HHi + HLo) / 2 + 3 * A10; LB = (HHi + HLo) / 2 - 3 * A10;
				if STok = false then begin FU = UB; FL = LB; STok = true; end
				else begin
					if UB < FU or PrevC > FU then FU = UB;
					if LB > FL or PrevC < FL then FL = LB;
				end;
				if TrUp and HCl < FL then TrUp = false
				else if TrUp = false and HCl > FU then TrUp = true;
				if TrUp then STv = FL else STv = FU;
			end;
			{ Bollinger(20, 2) width, population standard deviation }
			for k = 19 downto 1 begin CB[k] = CB[k - 1]; end;
			CB[0] = HCl;
			if NH >= 20 then begin
				smb = 0; for k = 0 to 19 begin smb = smb + CB[k]; end; smb = smb / 20;
				sqb = 0; for k = 0 to 19 begin sqb = sqb + Square(CB[k] - smb); end;
				BBW = 100 * 4 * SquareRoot(sqb / 20) / smb;
			end;
			PrevC = HCl; PrevH = HHi; PrevL = HLo;
			{ ----- 4h candles from the hours: pass 1 = finalize an unfinished earlier 4h, pass 2 = add, pass 3 = 4h end ----- }
			for q4 = 1 to 3 begin
				Do4 = false;
				if q4 = 1 then Do4 = Has4 and IntPortion(HB / 4) <> C4B;
				if q4 = 2 then begin C4B = IntPortion(HB / 4); L4C = HCl; Has4 = true; end;
				if q4 = 3 then Do4 = Has4 and Mod(HB, 4) = 3;
				if Do4 then begin
					N4 = N4 + 1;
					if N4 = 1 then EMA4 = L4C else EMA4 = EMA4 + 2 / 201 * (L4C - EMA4);   { pandas ewm(span=200, adjust=False) }
					if Mod(C4B * 4, 24) = 16 then begin                                   { the 4h candle opening 16:00 UTC = the daily close }
						for k = 120 downto 1 begin DC[k] = DC[k - 1]; end;
						DC[0] = L4C; ND = ND + 1;
						if ND >= 121 then begin                     { std of the last 20 / last 120 log returns, ddof 1 }
							m1 = 0; m2 = 0;
							for k = 0 to 119 begin lr = Log(DC[k] / DC[k + 1]); m2 = m2 + lr; if k < 20 then m1 = m1 + lr; end;
							m1 = m1 / 20; m2 = m2 / 120; s1 = 0; s2 = 0;
							for k = 0 to 119 begin lr = Log(DC[k] / DC[k + 1]); s2 = s2 + Square(lr - m2); if k < 20 then s1 = s1 + Square(lr - m1); end;
							if s2 > 0 then VR = SquareRoot(s1 / 19) / SquareRoot(s2 / 119) else VR = 0;
						end;
					end;
					Has4 = false;
				end;
			end;
			HasH = false;
		end;
	end;

	{ ===== paper books on this spot 15m close (order as Python run()) ===== }
	lt = 0;
	if he and N4 >= 200 then begin if cc > EMA4 then lt = 1 else lt = -1; end;
	anyOpen = BkOn[1] or BkOn[2]; gHit = false;
	if anyOpen then begin                                       { guard: 1% beyond the farthest open book stop }
		if BkOn[1] then gs = BkS[1] else gs = BkS[2];
		if gs = 1 then begin
			g = 1E12; for b = 1 to 2 begin if BkOn[b] and BkStop[b] < g then g = BkStop[b]; end; g = g * (1 - GuardPct / 100);
			gHit = ll <= g;
		end else begin
			g = -1E12; for b = 1 to 2 begin if BkOn[b] and BkStop[b] > g then g = BkStop[b]; end; g = g * (1 + GuardPct / 100);
			gHit = hh >= g;
		end;
		if gHit then begin BkOn[1] = false; BkOn[2] = false; end;
	end;
	if gHit = false then begin
		for b = 1 to 2 begin
			if BkOn[b] then begin
				if (BkS[b] = 1 and ll <= BkStop[b]) or (BkS[b] = -1 and hh >= BkStop[b]) then BkOn[b] = false
				else if (BkS[b] = 1 and hh >= BkTp[b]) or (BkS[b] = -1 and ll <= BkTp[b]) then BkOn[b] = false
				else begin
					if BkHalf[b] = false and ((BkS[b] = 1 and hh >= BkPt[b]) or (BkS[b] = -1 and ll <= BkPt[b])) then BkHalf[b] = true;
					if ok - BkT[b] >= MaxHours * 60 or (he and lt = -BkS[b]) then BkOn[b] = false;
				end;
			end;
		end;
		{ entries at the 1h close: needs 61 hours, 200 4h closes, ADX seeded }
		Ready = he and NH >= 61 and N4 >= 200 and ND >= 121 and STok;   { ND: vol filter ready (checker 2026-11-14) }
		if Ready then begin
			side = lt;
			if (cc > STv and lt <> 1) or (cc <= STv and lt <> -1) then side = 0;
			if BBW >= BBWMax then side = 0;
			if side <> 0 and ND >= 121 and VR >= VolRatioMax then side = 0;
			net = 0; for b = 1 to 2 begin if BkOn[b] then net = net + BkS[b]; end;
			if side <> 0 and net * side >= 0 then begin
				for b = 1 to 2 begin
					if b = 1 then lvl = Level1 else lvl = Level2;
					if BkOn[b] = false and ADXv > lvl then begin
						NextId = NextId + 1;
						BkOn[b] = true; BkS[b] = side; BkE[b] = cc; BkStop[b] = cc - side * StopAtr * A14; BkPt[b] = cc + side * HalfAtr * A14;
						BkTp[b] = cc + side * TargetAtr * A14; BkHalf[b] = false; BkT[b] = ok; BkR[b] = StopAtr * A14 / cc; BkId[b] = NextId;
					end;
				end;
			end;
		end;
	end;
	LastKey = ck;
	end;   { ck > LastKey }
end;

{ ---------- real side: copy the LONG books to MBT ---------- }
for b = 1 to 2 begin
	if BkOn[b] and BkS[b] = 1 then WantId[b] = BkId[b] else WantId[b] = 0;
	if RState[b] = 2 and RealId[b] <> WantId[b] then begin
		if WantId[b] > 0 then begin RealId[b] = WantId[b]; RR[b] = BkR[b]; RStop[b] = Close * (1 - RR[b]); end   { closed and reopened: keep the contract }
		else begin
			if b = 1 then Sell ("B1 Out") from entry ("BTC B1") next bar at market else Sell ("B2 Out") from entry ("BTC B2") next bar at market;
			RState[b] = 0;
		end;
	end;
	if RState[b] = 2 and StopLive[b] = false and Low <= RStop[b] then begin   { entry bar: the resting stop is not live yet }
		if b = 1 then Sell ("B1 Guard") from entry ("BTC B1") next bar at market else Sell ("B2 Guard") from entry ("BTC B2") next bar at market;
		RState[b] = 0; StopId[b] = RealId[b];
	end;
	if KillOn and RState[b] = 2 then begin
		if b = 1 then Sell ("B1 KILL") from entry ("BTC B1") next bar at market else Sell ("B2 KILL") from entry ("BTC B2") next bar at market;
		RState[b] = 0; StopId[b] = RealId[b];
	end;
	if RState[b] = 0 and WantId[b] > 0 and WantId[b] <> RealId[b] and WantId[b] <> StopId[b] then begin
		RealId[b] = WantId[b];
		if NoEntry = false and BookQty >= 1 then begin
			if b = 1 then Buy ("BTC B1") BookQty contracts next bar at market else Buy ("BTC B2") BookQty contracts next bar at market;
			RState[b] = 1; RR[b] = BkR[b];
		end;
	end;
	if RState[b] = 2 then begin
		if b = 1 then Sell ("B1 Stop") from entry ("BTC B1") next bar at RStop[b] stop else Sell ("B2 Stop") from entry ("BTC B2") next bar at RStop[b] stop;
		StopLive[b] = true;
	end;
end;

{ ---------- heartbeat (live guard; log only) ---------- }
if HeartbeatTag <> "" and GetAppInfo(aiRealTimeCalc) = 1 and LastBarOnChart then begin
	HB_Key = CurrentDate * 10000 + CurrentTime;
	if HB_Key <> HB_Last then begin
		HB_Day = NumToStr(CurrentDate + 19000000, 0);
		FileAppend("C:\TradingLogs\" + HB_Day + ".csv", "SIG," + HeartbeatTag + "," + GetSymbolName + "," + HB_Ver + ","
			+ NumToStr(MarketPosition * CurrentContracts, 0) + ",,,,,,,," + HB_Day + "," + NumToStr(CurrentTime, 0) + NewLine);
		HB_Last = HB_Key;
	end;
end;
