{ NQ VWAP Pullback ADX - MultiCharts PowerLanguage signal (longs only)

  Written from the trader's specification:
    1. A 1-minute close above the opening-range high (8:30-9:00 CT).
    2. Then a pullback to VWAP (a bar whose low touches VWAP).
    3. Then a 1-minute close back above VWAP,
    4. with ADX above 20 and not rising from the previous bar -> buy next bar.
    Target: highest high of the last 5 bars; stop: lowest low of the last 20
    bars (both fixed when the signal fires). Otherwise flat at ExitTime.
    One trade a day (the course's VWAP ADX list never had more than one).

  Apply to a 1-minute NQ / MNQ chart, Exchange time zone (Central), with the
  CME 24-hour session, so the midnight VWAP, the ADX and the 15:55 CT exit bar
  exist. Bar Magnifier is not needed on a 1-minute chart.

  Inputs to check:
    VwapAnchor   0 = VWAP from midnight (as in Vault Break); 830 = from the open.
    ExitTime     1555 = 3:55 PM CT as specified. If 3:55 PM Eastern was meant,
                 use 1455.
    LastEntryTime  no new entries from this time (not in the spec; 14:30 CT).

  The stop and target are sent as distances from the signal bar's close,
  which on a 1-minute chart is almost always the next bar's open.

  Python test (8:30 or 8:00 VWAP, ADX without overnight bars, 2018-2026):
  about 1,000 trades, 72% winners, profit factor 0.96 - no edge. That test
  cannot use the midnight VWAP or overnight ADX, so the MultiCharts backtest
  is the real test. }

Inputs:
	ORStart(830),
	OREnd(900),
	VwapAnchor(0),          { 0 = midnight; otherwise HHMM, e.g. 830 }
	ADXLength(14),
	ADXMin(20),
	TargetBars(5),
	StopBars(20),
	LastEntryTime(1430),
	ExitTime(1555),
	MaxTradesPerDay(1),
	UseHolidayTimes(true),
	EarlyLastEntry(1100),
	EarlyExitTime(1145),
	NumContracts(1);

Variables:
	BarVol(0), CumPV(0), CumVol(0), VW(0), VwapOn(false),
	ORHigh(0), Broke(false), Pulled(false), ADXv(0),
	TgtPx(0), StopPx(0), TgtPts(0), StopPts(0),
	DayStartTrades(0), TradesToday(0),
	CalMonth(0), CalDay(0), CalDow(0), CalYear(0), IsWeekday(false), IsEarlyClose(false),
	DayLastEntry(0), DayExit(0);

if BarType < 2 then BarVol = Ticks else BarVol = Volume;
ADXv = ADX(ADXLength);

{ ---------- New calendar date ---------- }
if Date <> Date[1] then begin
	ORHigh = 0;
	Broke = false;
	Pulled = false;
	DayStartTrades = TotalTrades;
	if VwapAnchor = 0 then begin
		CumPV = 0;
		CumVol = 0;
		VwapOn = true;
	end
	else
		VwapOn = false;
end;

{ ---------- VWAP ---------- }
if VwapAnchor > 0 and VwapOn = false and Time > VwapAnchor
	and (Date <> Date[1] or Time[1] <= VwapAnchor) then begin
	CumPV = 0;
	CumVol = 0;
	VwapOn = true;
end;
if VwapOn then begin
	CumPV = CumPV + (High + Low + Close) / 3 * BarVol;
	CumVol = CumVol + BarVol;
	if CumVol > 0 then VW = CumPV / CumVol;
end;

{ ---------- Opening range high ---------- }
if Time > ORStart and Time <= OREnd then begin
	if ORHigh = 0 then ORHigh = High else ORHigh = MaxList(ORHigh, High);
end;

{ ---------- CME holiday half-days ---------- }
CalMonth = Month(Date);
CalDay = DayOfMonth(Date);
CalDow = DayOfWeek(Date);
CalYear = Year(Date) + 1900;
IsWeekday = CalDow >= 1 and CalDow <= 5;
IsEarlyClose = UseHolidayTimes and (
	(CalMonth = 1 and ((CalDay = 1 and IsWeekday) or (CalDay = 2 and CalDow = 1)))
	or (CalMonth = 1 and CalDow = 1 and CalDay >= 15 and CalDay <= 21)
	or (CalMonth = 2 and CalDow = 1 and CalDay >= 15 and CalDay <= 21)
	or (CalMonth = 5 and CalDow = 1 and CalDay >= 25)
	or (CalMonth = 6 and CalYear >= 2022 and ((CalDay = 19 and IsWeekday)
		or (CalDay = 18 and CalDow = 5) or (CalDay = 20 and CalDow = 1)))
	or (CalMonth = 7 and (((CalDay = 3 or CalDay = 4) and IsWeekday) or (CalDay = 5 and CalDow = 1)))
	or (CalMonth = 9 and CalDow = 1 and CalDay <= 7)
	or (CalMonth = 11 and CalDow = 4 and CalDay >= 22 and CalDay <= 28)
	or (CalMonth = 11 and CalDow = 5 and CalDay >= 23 and CalDay <= 29)
	or (CalMonth = 12 and (((CalDay = 24 or CalDay = 25) and IsWeekday) or (CalDay = 26 and CalDow = 1))));
if IsEarlyClose then begin
	DayLastEntry = EarlyLastEntry;
	DayExit = EarlyExitTime;
end
else begin
	DayLastEntry = LastEntryTime;
	DayExit = ExitTime;
end;

{ ---------- Setup: breakout, pullback, reclaim ---------- }
TradesToday = TotalTrades - DayStartTrades;
if MarketPosition <> 0 then TradesToday = TradesToday + 1;

if Time > OREnd and Time < DayLastEntry and ORHigh > 0 and VW > 0 then begin
	if Broke = false then begin
		if Close > ORHigh then Broke = true;
	end
	else begin
		if Low <= VW then Pulled = true;
		if Pulled and Close > VW and ADXv > ADXMin and ADXv <= ADXv[1]
			and MarketPosition = 0 and TradesToday < MaxTradesPerDay then begin
			TgtPx = Highest(High, TargetBars);
			StopPx = Lowest(Low, StopBars);
			if TgtPx > Close and StopPx < Close then begin
				TgtPts = TgtPx - Close;
				StopPts = Close - StopPx;
				Buy ("VWAP PB") NumContracts contracts next bar at market;
			end;
		end;
	end;
end;

{ ---------- Exits ---------- }
SetStopContract;
if StopPts > 0 then begin
	SetStopLoss(StopPts * BigPointValue);
	SetProfitTarget(TgtPts * BigPointValue);
end;

if MarketPosition > 0 and Time >= DayExit then
	Sell ("VWAP PB EOD") this bar on close;
