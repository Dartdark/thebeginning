{ SessEffForecast  (PowerLanguage FUNCTION, return type: Numeric, storage: Auto-detect / Series)

  FORECAST of the current session's Kaufman efficiency ratio, made only from completed past sessions.
  Model: logistic regression on 15 daily features ("Telonics" next-day-ER model), fitted once on NQ 2010-07..2018-12,
  one model per bar size (3, 5 or 15 minutes; the ER and its features are measured on that bar size). It estimates the
  probability that today is MORE efficient (trendier) than a median day, and an expected ER from a linear calibration.

  Honest strength: weak. Correlation of the forecast with the day's actual ER is ~0.10-0.15 (2019-2025 out of sample);
  low-forecast days averaged 5-min ER ~0.12 vs ~0.145 for high-forecast days. Use it as a tilt, not a switch.

  Needs >= 65 complete sessions on the chart before it outputs anything, and >= 252 sessions to reproduce the reference
  values exactly (the "chop" feature uses a 1-year median). Load at least 13 months of 1-minute (or 5-minute) data.

  Outputs: oP        probability today is an above-median-efficiency day (-1 = not enough history yet)
           oExpER    expected ER for today on TFMinutes bars (linear calibration of oP; -1 = n/a)
           oBucket   1 = low (bottom third of the training forecasts), 2 = mid, 3 = high, 0 = n/a
           oPrevER   last complete session's actual ER on TFMinutes bars (-1 = n/a)
  Returns oP. During a session the values are the forecast FOR that session; after the close they switch to the forecast
  for the NEXT session. Session times in the chart's time zone (930/1600 ET, 830/1500 Central). }

            end;
            Feat[4] = S1 / 20;
