{ NQ Opening Drive - MultiCharts PowerLanguage signal

  Follows the direction of the first 30 minutes of the regular session.
  Built from scratch for the multi-strategy plan; it shares no logic with
  NQ VWAP Momentum (no VWAP, no pullback trigger) and trades a different
  window, so its daily results are close to uncorrelated with it.

  Apply to a 5-minute NQ / MNQ chart, Exchange time zone (Central). The chart
  needs the 8:30 CT open bar; pre-market bars are fine but not needed.

  RULE (one trade a day)
    At the close of the 9:00 CT bar, measure the move from the first regular-
    session open (the open of the first bar after 8:30 CT) to the 9:00 close.
      move >= +MinMovePct  ->  buy next bar at market
      move <= -MinMovePct  ->  sell short next bar at market
    Stop: StopPts from entry. No profit target.
    Exit: at the close of the 11:00 CT bar.
    Holiday half-days: the same times apply (flat by 11:00, before the halt).

  Backtest (Python on 1-minute data, 2018-2026, 1 NQ, after $7.25 costs):
    1,352 trades, 41% winners, average $119, profit factor 1.23.
    Confirm with a MultiCharts backtest before trading it.
  Backtest properties to use: no commission or slippage (costs are added in
  the analysis), Bar Magnifier on at 1 minute. }

Inputs:
	OpenTime(830),          { regular session open (CT) }
	DecideTime(900),        { measure the opening move at the close of this bar }
	ExitTime(1100),         { close the trade at the close of this bar }
	MinMovePct(0.2),        { minimum % move from the open to trade }
	StopPts(50),
	NumContracts(1);        { 1 for NQ backtests; 10 MNQ = 1 NQ }

Variables:
	SessOpen(0), HaveOpen(false), MovePct(0), TradedToday(false);

{ New day: forget yesterday's open }
if Date <> Date[1] then begin
	HaveOpen = false;
	TradedToday = false;
end;

{ First bar that closes after the open: its open is the session open }
if HaveOpen = false and Time > OpenTime and (Date <> Date[1] or Time[1] <= OpenTime) then begin
	SessOpen = Open;
	HaveOpen = true;
end;

{ Entry: decision on the DecideTime bar, fill at the next bar's open }
if HaveOpen and Time = DecideTime and MarketPosition = 0 and TradedToday = false and SessOpen > 0 then begin
	MovePct = (Close / SessOpen - 1) * 100;
	if MovePct >= MinMovePct then begin
		Buy ("Drive L") NumContracts contracts next bar at market;
		TradedToday = true;
	end
	else if MovePct <= -MinMovePct then begin
		SellShort ("Drive S") NumContracts contracts next bar at market;
		TradedToday = true;
	end;
end;

{ Stop, per contract }
SetStopContract;
SetStopLoss(StopPts * BigPointValue);

{ Time exit }
if MarketPosition <> 0 and Time >= ExitTime then begin
	Sell ("Drive LX") this bar on close;
	BuyToCover ("Drive SX") this bar on close;
end;
