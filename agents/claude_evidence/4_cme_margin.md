# Evidence sheet 4: CME margin changes force futures deleveraging
Verdict: **DON'T TEST.** Rank 4.

1. **Who trades and why.** When CME Clearing raises ES / NQ performance-bond margins (clearing advisories, usually
   effective 1-2 days later), leveraged futures holders must add collateral or cut positions.
2. **Direction, size, timing?** Timing known (advisory date, effective date). Direction: hikes → selling, cuts →
   buying, in theory. **Size unknown**: most holders post more collateral; the forced part can't be estimated.
3. **Reaches NQ?** Yes, directly.
4. **Separates from momentum?** Poorly: hikes follow volatility spikes, so any test mixes the margin effect with
   post-spike behaviour.
5. **Gap?** Effective-date opens, ~8:30 CT: in the empty morning window.
6. **Power.** A handful to ~10 changes a year (to count from CME advisories) → ~30-50 events in 2018-22; NQ day sd
   1.5% → needs ≈ 0.45-0.55% a day. Not realistic.
7. **Already tested?** Not in TIER_LIST. The idea fails on size and power before any data is needed.
