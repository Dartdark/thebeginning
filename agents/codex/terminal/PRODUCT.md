# Beginning Research Terminal

A local research workspace for the user overseeing Claude/Codex research in Dartdark/thebeginning.
The user needs to inspect completed tests, preserve negative evidence, find review prerequisites and understand
portfolio comparisons with minimal file hunting. It serves existing reports, evidence, plans, scout records,
execution references and supported saved CSV files. The separate scout automation does the research.

The app is Python standard-library HTTP on localhost with plain HTML/CSS/JavaScript, a dark interface, native
controls and no frontend build process. Notes and imported PDFs stay in the existing Git-ignored runtime folder.
Pull `codex/work` outside the app, then refresh. Neither an open terminal nor “ready” scout progress proves
an analyst is currently running. Import/discovery is not analysis or a return test.

Scope of the 2026-11-02 update: oversight overview, strategy record detail, registered account-result comparisons,
shared design rules and reproducible UI review. Historical numbers remain the saved results of their exact studies;
no new strategy, retest, approval or live integration is implied. Never operate the VPS, broker, API keys or trading.
