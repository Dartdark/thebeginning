## Availability is not authenticated by these maker definitions

The inspected source maps`reportedDate`plus pre-/post-market classification into a trading session
and consumes vendor`surprisePercentage`. That does not establish the original public-release time,
which numerical EPS version was first released, which consensus snapshot existed before the release,
how estimates were later revised, or local receipt/processing time. Fixed modern approximate ticker
weights likewise do not establish historical announced index weights/membership.

No earnings CSV header/schema was opened after discovering this prior counterpart. Therefore this
note does **not** claim to have audited the actual file or proved that every possible extra timestamp
column is absent. The narrow finding is that the source definitions establish no authenticated
point-in-time consensus/revision/release binding for a new claim. Assuming retrospective EPS values
were available at the original event would violate the current information-clock requirement.

A genuinely new authenticated vintage/receipt input could support a separately reviewed data question,
but there is none established by this bounded check. That is not permission to repair the old test,
reinterpret its outcomes, pick a new weighting rule or launch a generic earnings-day price port.

## Decision

**DON'T TEST this nomination; stop before the earnings schema/value stage.** The proposed independent
EPS-surprise and announced-calendar families already have exact source counterparts. No eight-question
TEST sheet, source intake or economic preregistration is justified for a renamed repeat. This does
not assert that all future earnings-related research is impossible; it records the finite current
eligibility result. H07 and all closed studies retain their existing frozen rules and history.
