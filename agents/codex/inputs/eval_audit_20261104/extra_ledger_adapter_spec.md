# Existing-source adapter contract — FC2B, ST, PT and VCS

Summary: Four existing source trade lists can be normalized without regenerating signals or introducing strategy variants.
The adapter is code only; it has not loaded historical trades into a new return/path test or written new ledgers.
It preserves report prices, explicit exit kinds, native-unit costs, source sampling bounds and missing/touch flags.
ATR/range risk is reconstructed from past owned inputs; original-report-feed parity and independent economic verification remain pending.
No live configuration, plan allocation or broker setting changes are authorized by this artifact.

Adapter: `analysis/codex_eval_extra_ledgers_20261104.py`. Its `SPECS` pins the existing CSV, workbook and PowerLanguage paths. `source_manifest()` is metadata only. `build(config_path, prereg_commit, {"NQ": Grid24}, keys=None)` checks exact committed code/config/frozen files plus every source input hash before normalization. The root's research preregistration controls admission and return work. The CLI `build --config PATH --prereg-commit FULL_SHA` uses the root's registered raw-file paths through the existing path builder.

The default outputs, generated only after preregistration, are `agents/codex/runtime/eval_audit_20261104/ledgers/{FC2B,ST,PT,VCS}_unit_ledger.csv` and `extra_ledgers_receipt.json`. Config must hash the four PowerLanguage sources, four MC workbooks and three CSVs and list the adapter among `frozen_files`. The receipt preserves source hashes, settings, generated-ledger hashes and gap/touch counts.

This is not a rerun of the entry signals. In particular, VCS does not substitute price proxies for lagged ES flow inputs; it reads the existing source tickets. PT means Claude's saved v2 and corresponding MC export, not an unavailable original user source. ST means saved MCv3, not the older CODE_BE rebuild. Prior search/variant history remains attached to those families.

Prices remain source prices. `gross` is `(exit−entry)×side×$2` for one MNQ; source CSV `gross` is checked against one NQ price arithmetic. `fee_units=1` and `slippage_one_tick=$0.50×(1+[exit is not target])` are cost units, not a net-return assumption. The root's actual micro commission and slippage scenarios apply later. Workbooks retain source chart compression and Bar Magnifier settings in the receipt.

Native timestamps are close labels of the one-minute candle containing an inferred fill. Market entries first seek the source chart bar's first native open; time exits seek their source open/close. Known market-open/close clocks remain fixed even when the source price mismatches the owned native open/close; the adapter sets `entry_touch/exit_touch=False` and exact-phase false so account admission can treat the mismatch as UNKNOWN. It never searches an earlier/later price touch to change a known order clock or add unstated latency. Only genuine resting stop/limit orders search for their first observed touch inside that same source candle. No touch preserves the expected source time with a false touch flag. No crossing into another source candle or fabricated native price is allowed. A target's observed one-point trade-through is flagged, not silently enforced by inventing a replacement exit.

`stop_points_at_entry` uses the declared source formula on the owned feed, never a future exit/realized-loss inference. It is NaN until warmup is available and whenever its required lookback has detected missing native inputs. `stop_points_owned_feed_estimate` retains the incomplete-input estimate for diagnosis only; it cannot authorize risk sizing. `risk_input_missing_bars` is retained and `-1` means insufficient history. ST's explicitly coded shortened-day fallback remains part of the source rule. VCS reuses the frozen builder's strict source-calendar ATR helper: it checks the complete first-to-last observed candle span, including wholly absent internal candles, and excludes only documented frozen closure minutes. ST/PT range completeness checks all native OHLC fields. Neither this flag nor a finite formula certifies every absent leading/trailing session minute; registered raw-coverage/calendar gates remain necessary. A finite risk value does not waive an unresolved material gap. ST shortened-day fallback follows source behavior; PT does not bank shortened sessions. VCS uses midnight-aligned five-minute candles, retaining their previous-date minutes rather than substituting one-minute calendar ATR.

Every held native minute is checked without forward-fill. `missing_held_bars=-1` means outside-owned-grid/reversed inference, not zero missing data. Cross-session positions and late exits are retained for account admission; they are not deleted or made flat. Unknown exit labels, unfinished workbook pairs, missing fields and source price/gross-unit contradictions raise errors. A failed adapter is a source gap, not evidence of zero strategy trades.

Validation before historical execution: Python compilation, import without source I/O and synthetic kind/timestamp assertions passed. `selftest` additionally proves that a 10:00 close-price mismatch cannot move an exit to an earlier 09:57 touch, an open mismatch cannot add later fill latency, a resting stop may still infer the 09:57 touch, and an entry lower bound cannot shift a known chart-bar-open clock. An additional synthetic fixture removed an entire internal five-minute candle and confirmed the VCS risk lookback reports missing input. No historical normalization, strategy returns, account outcomes or candidate comparison has run in this subtask.
