//  CORE HYPOTHESIS
FROM NOISE
TO BREAKOUT.
R2Vault uses a rolling linear regression to
separate two different questions: how well a line
describes recent prices, and which direction that
line points. Low R2 creates the reference
structure; positive slope selects the long side.
The development deliberately remained limited to
two strategy versions. No dedicated parameter
optimization was performed on the out-of-sample
segment, reducing opportunities to fit historical
noise.
//  IMPORTANT SCOPE
This is a systematic research model based on
closing prices. It does not use order flow, volume
profile, or a forward-looking volatility forecast.
//  WORKFLOW
R2 near zero stores the candle range. Positive
slope enables a buy stop above that range plus a
proportional noise buffer.

//  REGRESSION MECHANICS
R2 AND SLOPE.
//  LOW R2: WEAK EXPLANATORY FIT
R2 is the coefficient of determination over the
last 576 closes. It measures the fraction of
price variance explained by the regression line:
0 means no linear explanatory power, while 1 is
a perfect linear fit. R2 has no direction because
it is squared.
Slope is the direction of the fitted line. In this
implementation the most recent bars receive
higher X values, so Slope > 0 means the fitted
relationship rises toward the present. R2
answers fit quality; Slope answers direction.
//  OFFICIAL THRESHOLD
R2ZeroThreshold = 0.030. A vault is created when the line explains no more than 3% of observed variation: an
extremely weak linear structure.

//  STRUCTURE AND ENTRY
THE VAULT.
//  ENTRYLEVEL = VAULTHIGH + (VAULTRANGE X 0.20)
//  VAULT
If R2 <= 0.030, the current High and Low replace
the stored vault. VaultRange is High minus Low.
//  FILTERED BREAKOUT
The buy stop is placed above VaultHigh plus 20%
of VaultRange, only in-session, with Slope > 0, and
at most three entries per day.

//  LIMITS AND NEXT STEPS
VERDICT.
R2Vault is a compact and testable proposition:
weak linearity defines a local range, positive slope
selects direction, and the proportional noise filter
requires a more meaningful breakout.
The limited two-version development and
absence of out-of-sample optimization are
deliberate anti-overfitting choices. They reduce,
but do not eliminate, model risk or regime risk.
//  NEXT STEPS
Validate costs and fills, stress R2Length and noise sensitivity, formally preserve the in-sample/out-of-sample split, and
observe forward simulation without ad hoc changes.
//  DISCLAIMER
This document is descriptive, not financial advice. Historical and simulated results are not indicative of future results.
