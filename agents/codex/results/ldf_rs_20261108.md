## What could make this wrong

The330minutevariance scaling inherits a fixed-model approximation; intraday returns need not be independent
or homoskedastic, and Z1.25is a rule threshold, not a calibrated probability. EWMA state is causal but source
predecisionforwardfill and incompletecontract metadata remain limitations. Finaldata can have vendor revisions.
SourceATRusesweekdayfullcalendar-dayranges rather than true exchange-sessionAUMflow; no actualfunddemand
was measured. Coststressholdingfixedorders does not capture all slippage-inducedstopchanges. The nextbarOPEN
fill is a bar-model assumption; one-minute replay is an explicit sensitivity, not real latency measurement.

This hypothesis was proposed after morningRS/LDFand broad ingredient outcomes were alreadyknown.13earlier
