## Five paper-review questions

**1. What is it about?** Aarav Shah, *Pair Trading in Leveraged ETFs: Analysis of a Cross-Jurisdictional
Strategy Profitability*, July6,2026, SSRN7065278. It trades deviations between US TQQQ and London's LQQ3,
converting the latter from pence into dollars using GBPUSD. Both seek leveraged Nasdaq100 exposure, but
these are different issuers/securities, not fungible dual listings. WisdomTree's product is a debt ETP;
TQQQ is a ProShares ETF. Matching index labels do not eliminate financing, reset, structure or tracking risk.

**2. What does it find?** The following are author claims, not our backtest:

The annualization is internally consistent with405observations. The source's Sharpe is excess **CAGR** divided
by annualized volatility, rather than the conventional annualized mean daily excess return divided by daily
standard deviation. A large reported ratio does not establish statistical significance. Windows10/20/30/40/50
and several entry/exit bands were compared on the same sample; no independent holdout is established.

**3. Why does it make money, if it does?** The proposed mechanism is convergence of temporary cross-market
pricing deviations between similar leveraged exposures. An actual tradable convergence premium is not
demonstrated by our audit. Asynchronous marks, price-unit transformations and differing instruments can
create apparent deviations without an executable spread. There is no identified forced counterparty here.
The paper's small drawdown/near-zero beta do not establish protection against future crashes or margin calls.

**4. Can we build on it?** Retain the accounting and synchronization lessons. Reject this implementation as
portfolio evidence. It has no place as written in the50K/150K evaluation or funded futures plans: it trades

native input evidence and a separately registered corrected protocol, not an invitation to optimize this curve.
No promising-strategy queue promotion is warranted. The conditional reproduction inputs are retained in
[DATA_NEEDED](../DATA_NEEDED.md); free sources only.

**5. Can strategy code be made?** Yes in principle: a Python two-leg statistical-arbitrage engine, rather than
a single-series NQ directional strategy. The author code already describes an algorithm, but is not an
admitted economic implementation. Production research would require metadata-based units/splits, synchronized
available-at quotes and later fills, FX holdings, integer share quantities, collateral, borrow availability,
financing and native two-leg costs. A corrected exit convention and capital basis must be fixed before returns.
Code feasibility does not establish profitability. No MultiCharts strategy was written after the failed gate.

## Rule (as inspected; no historical strategy test)

The baseline takes the TQQQ/LQQ3-dollar ratio, a20-observation EMA and20-observation rolling standard deviation.
It buys the US/sells the UK leg below z=−0.75 and reverses those legs above+0.75. The written exit is
absolute z<0.25; code instead exits a prior long when z>−0.25 and a prior short when z<+0.25. Thus it also
exits overshoots outside the written band. This is a specification mismatch, not an inherently irrational exit.
The source selects hourly OPEN at TIME160000, joins by date and charges0.15%of assumed NAV per signal change.
Its return uses the previous signal. That lag alone does not establish synchronized quotes or causal fills.
