## 1. What is it about?

Long-only, 15-minute US100 Donchian trend following with ATR-based stops and sizing.
The public text tests January 2023–April 2026 and compares fixed-dollar risk with percentage sizing.

## 3. Why does it make money, if it does?

The proposed mechanism is trend persistence with losses cut and winners allowed to run.
Our interpretation: long-only Nasdaq exposure, the selected sample and sizing may contribute.
A Nasdaq-based system beating SPY does not isolate timing skill from different index exposure.
A matched Nasdaq buy/hold and simpler trend-rule control are needed before attributing incremental alpha.

Static source observations, not runtime tests:
- EntrySignal compares the last closed candle with a 160-bar channel starting at shift 2.
- Channel exit uses 60 bars; ATR uses 80, with initial-stop multiplier 1.5 and trailing multiplier 2.
- OnTick invokes management/signals only once per new bar; trailing management is not recalculated on every tick.
- Default direction is long-only, maximum one own position, no fixed target and no session filter.
- There is no mandatory daily close/flatten routine.
- The reference-risk filter defaults on: a signal must support a valid minimum lot at a fixed $10 reference risk.
  This broker-specific eligibility filter must be preserved or explicitly changed during a port.
- Default percentage risk is 2%, not the paper's highlighted 1.75% or fixed-dollar arm. Report inputs must be loaded explicitly.
