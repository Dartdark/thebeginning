## Five paper questions

1. **What is it about?** NG futures returns around weekly EIA storage announcements, using daily and five-minute
   data over March2003–December2018. Daily analysis covers several nearby maturities.
2. **What does it find?** Historically negative NG announcement returns concentrate around release time and
   persist after several controls. The proposed short profits in the full sample, but fails costs in its later panel.
3. **Why does it make money, if it does?** No established durable forced-flow explanation. The authors call the
   negative premium puzzling and associate its decline with improved forecast accuracy. Positive-surprise
   conditioning is retrospective: the surprise becomes known at release, after the proposed short entry.
4. **Can we build on it?** Not as a supported current unconditional diversification candidate. Its own later cost
   result is adverse. A materially new mechanism/input would need independent evidence and a separate registration;
   changing windows, side or filters is not an authorized rescue of this source rule.
5. **Can strategy code be made?** Yes: a scheduled directional short,90minutes before each eligible release,
   cover30minutes afterward. A real implementation needs admitted as-of event clocks, contract/roll mapping,
   native fills/costs and an explicit risk protocol. Code feasibility does not establish net profitability.
