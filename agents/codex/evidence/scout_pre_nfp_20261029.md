## 1. Who trades, and why?
Investors bear uncertainty about how an impending macro release will affect prices. The source proposes
compensation that resolves before news rather than only at news. This is an explicitly stated risk-premium
hypothesis, not evidence that a participant must buy ES. Changing announcement regimes or faster repricing can
remove it. Actual scheduled payroll announcements remain observable; the source effect is unverified today.

## 2. Direction, size and timing before entry
Long ES only before actual BLS Employment Situation dates corroborated by previous-month release notices.
Public availability is conservatively the archived preceding release's date+one full calendar day, weeks
before entry. No surprise or reported payroll value is used. Select the17:06-labelled minute open on the prior
calendar date (wall-clock17:05CT) and exit at the07:25CT minute close, five minutes before08:30ET release.
Date-aware ET/CT conventions match the observed fixed one-hour offset. Use a protective1.0ATR15stop based on
the prior calendar date's already-known ATR. One position, no target/reentry. Unverified quote/latency savings
are not assumed; shared engine plus explicit market/stop slippage is a bar-replay approximation.
